# Temario de la Clase 16: Presentación de Proyectos, Conclusiones y Ruta Futura (60 minutos)

**Objetivo:** Concluir formalmente el curso revisando y retroalimentando las visualizaciones y modelos de los alumnos, establecer mejores prácticas para publicar proyectos en GitHub y diseñar una ruta de aprendizaje personalizada para continuar su formación en Ciencia de Datos e Inteligencia Artificial.

---

### 1. Sesión de Retroalimentación del Proyecto Final (25 minutos)
* **Revisión del Valuador Inmobiliario:** Espacio interactivo para que los alumnos compartan sus hallazgos del EDA (relaciones, correlaciones) y la precisión de sus modelos predictivos de la CDMX.
* **Debate Crítico:** Análisis de limitaciones y supuestos de los modelos de regresión y cómo la calidad de los datos afecta directamente las valuaciones.

### 2. Creación de un Portafolio Profesional en GitHub (15 minutos)
* **Importancia del Portafolio:** Por qué el portafolio en GitHub es la carta de presentación obligatoria para un Científico de Datos.
* **Estructura Recomendada:** Organización de carpetas de proyectos, escritura de archivos `README.md` claros que expliquen el problema de negocio, la metodología del EDA, el modelo matemático y las conclusiones ejecutivas.

### 3. Ruta de Aprendizaje Futura (15 minutos)
* **¿Qué sigue después de este curso?:**
  - **Fundamentos Estadísticos:** Inferencia estadística y pruebas de hipótesis.
  - **SQL y Bases de Datos:** Extracción y manipulación de datos desde servidores relacionales (Bases de datos SQL).
  - **Machine Learning Avanzado:** Algoritmos como Random Forest, Gradient Boosting (XGBoost) y conceptos de Deep Learning (Redes Neuronales).
  - **Manejo de Modelos en Producción (MLOps):** Cómo desplegar un modelo en una API activa.

### 4. Cierre y Entrega de Conclusiones (5 minutos)
* **Agradecimiento final:** Reflexión sobre la importancia de la curiosidad, el aprendizaje constante y la ética en el manejo de datos.
