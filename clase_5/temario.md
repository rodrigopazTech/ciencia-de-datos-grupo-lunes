# Temario de la Clase 5: Modularidad en Python y Configuración del Entorno Local (60 minutos)

**Objetivo:** Comprender la creación y ejecución de código empaquetado en Funciones, importar librerías externas mediante Módulos y configurar el entorno local profesional utilizando Anaconda y Jupyter Lab.

---

### 1. Creación de Código Reutilizable: Funciones (`def`) (20 minutos)
* **Sintaxis y Estructura:** Declaración de funciones mediante la palabra reservada `def`, uso de parámetros y argumentos.
* **Retorno de Valores:** La sentencia `return` frente a `print()`. Diferencia entre mostrar un mensaje e inyectar un valor procesado al flujo del programa.

### 2. Importación y Uso de Librerías: Módulos (15 minutos)
* **¿Qué es un Módulo?:** Archivos de código externo que expanden las capacidades de Python.
* **Sintaxis de Importación:** Uso de `import`, importación selectiva (`from ... import`) y asignación de alias cortos (`import ... as ...`) preparando la convención para NumPy (`np`) y Pandas (`pd`).

### 3. Configuración del Entorno Data Science Local (15 minutos)
* **Anaconda:** Explicación del ecosistema estándar en Ciencia de Datos y gestor de paquetes.
* **Jupyter Lab:** Apertura y uso del entorno de desarrollo local. Comparativa de ventajas y diferencias frente a Google Colab.

### 4. Taller de Cierre (10 minutos)
* **Ejercicio práctico:** Configurar Jupyter Lab de forma local (o simular en Colab en caso de requerirse soporte de instalación), crear un nuevo notebook, definir una función personalizada que use una librería importada (por ejemplo, calcular una raíz con `math` o generar un número con `random`) y ejecutarla localmente.
* **Cierre:** Conexión pedagógica hacia la Clase 6 (Ingresar formalmente a NumPy para cómputo numérico).
